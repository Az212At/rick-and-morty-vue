# Rick and Morty · Vue

Каталог персонажей и эпизодов «Рика и Морти» на данных публичного [Rick and Morty API](https://rickandmortyapi.com/).

## Стек

- Vue 3, Composition API и компоненты с `<script setup lang="ts">`.
- TypeScript со строгой проверкой типов.
- Vue Router с `createWebHashHistory` для работы на статическом хостинге.
- Vite, CSS, локальные шрифты Inter.
- Нативный Fetch API и AbortController.
- ESLint с правилами Vue и TypeScript, Stylelint, Prettier.
- Vitest, Vue Testing Library, Vue Test Utils и jsdom.

## Запуск

Нужны Node.js 22.12+ и Yarn 1.22.

```bash
yarn install --frozen-lockfile
yarn dev
```

Локальный адрес: [http://localhost:8080/rick-and-morty-vue/](http://localhost:8080/rick-and-morty-vue/).

```bash
yarn build          # проверка TypeScript и production-сборка в dist/
yarn preview        # просмотр production-сборки на порту 4173
yarn type-check     # проверка типов приложения и Vite-конфига
yarn lint           # ESLint без изменения файлов
yarn lint:fix       # ESLint с автоисправлением
yarn stylelint      # проверка CSS
yarn test           # все тесты однократно
yarn test:watch     # тесты в режиме наблюдения
yarn format:check   # проверка форматирования
yarn format        # форматирование
```

## Возможности

- Каталог персонажей с поиском по имени и фильтром по статусу.
- Модальное окно с происхождением, местоположением, полом, видом и числом появлений персонажа. Данные используются из загруженного списка.
- Каталог эпизодов с поиском и датами выхода.
- Пагинация обоих каталогов. Поиск, фильтр и номер страницы сохраняются в URL и поддерживают навигацию браузера.
- Состояния загрузки, пустого результата и ошибки с повторной попыткой.
- Отмена устаревших запросов при смене страницы и размонтировании компонентов.
- Адаптивная вёрстка для телефонов, планшетов и широких экранов.
- Управление с клавиатуры, видимый фокус, ссылка перехода к содержимому, доступные подписи полей и модальное окно с Escape и восстановлением фокуса.

Интерфейс на русском языке; имена и остальные данные API показываются в исходном виде.

## Структура

Проект сохраняет слои Feature-Sliced Design:

```text
src/
  app/          # точка входа, маршруты, основной layout и стили
  pages/        # страницы персонажей, эпизодов и 404
  widgets/      # шапка и футер
  features/     # просмотр деталей персонажа
  entities/     # типы, API-пути и карточки персонажей и эпизодов
  shared/       # HTTP-клиент, composable запросов, UI, утилиты и ресурсы
  test/         # интеграционные тесты, тесты API и жизненного цикла запросов
```

Локальное состояние интерфейса хранится в `ref` и `shallowRef`, производные значения — в `computed`, а состояние поиска — в URL. Запросы вынесены в общий типизированный composable `useResource`, который принимает реактивный путь и отменяет запросы при его изменении и размонтировании компонента. Типизированные props и события задают контракты компонентов; данные из API не оборачиваются в глубокие реактивные прокси. Внешний глобальный стор не требуется.

## Маршруты и публикация

- `#/characters` — персонажи (страница по умолчанию).
- `#/episodes` — эпизоды.
- Неизвестный маршрут показывает страницу 404.

Демо: [az212at.github.io/rick-and-morty-vue](https://az212at.github.io/rick-and-morty-vue/).

Vite использует `base: "/rick-and-morty-vue/"` для GitHub Pages. Для размещения в корне другого домена поменяйте `base` на `"/"` и соберите проект заново. Vue Router с `createWebHashHistory` позволяет обновлять вложенные страницы без дополнительных правил сервера. Страницы загружаются через динамические импорты.

Для публикации или обновления демки выполните `yarn deploy` из Vue-проекта. Скрипт собирает приложение и отправляет содержимое `dist` в ветку `gh-pages` текущего `origin` (`Az212At/rick-and-morty-vue`). Нужны настроенные Git-учётные данные с правом записи. Ветка исходников `master` при этом не перезаписывается.

В **Settings → Pages** необходимо выбрать **Deploy from a branch → gh-pages → /(root)** после первого успешного деплоя. Если раздел Pages недоступен, включить публикацию должен владелец или администратор репозитория. Пустой `public/.nojekyll` отключает обработку готовой сборки через Jekyll.

Исходный [дизайн-макет в Figma](https://www.figma.com/community/file/1225458908057208058/rick-and-morty).
